# HLDS Address-Scoped Challenge Cache Diagnostic

Prompt: `HL-CL-20260504-269-dedicated-goldsrc-hlds-address-scoped-challenge-cache-diagnostic-surface`

Compatibility claim level: `diagnostic-address-scoped-challenge-cache-only; no real Steam Half-Life or HLDS-compatible client compatibility claimed`

## Scope

This diagnostic bridge stores deterministic getchallenge outputs in a bounded cache keyed by the loopback remote endpoint and validates connect-shaped diagnostic packets against that endpoint. It remains diagnostic-only: no Steam auth, no netchan, no reliable channel, no resource baselines, no signon state, and no client admission.

## Cache Policy

- challenge_cache_enabled: 1
- challenge_cache_key: remote_loopback_endpoint
- key material: address family + loopback address + loopback UDP source port
- challenge_cache_max_entries: 8
- challenge_ttl_policy: ttl_ticks=3
- deterministic created tick: 10
- challenge_one_shot: 1
- public_socket_opened: 0
- loopback UDP bind: 127.0.0.1 ephemeral port in all UDP scenarios
